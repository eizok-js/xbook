# X簿（エックスぼ）

X運用の家計簿。毎日少し記録して、AIと振り返る。

X簿は、Xを始めたばかりの個人ユーザーが、毎日の運用を簡単に記録し、AIと一緒に振り返るためのローカルデスクトップアプリケーションです。専門的なマーケティング分析ではなく、家計簿のように「少し記録する」「あとで振り返る」ことを目的としています。

## できること

- 日付・フォロワー数・「今日やったこと」を記録する
- フォロワー数の推移をグラフで見る
- AI（Gemini）に記録を振り返ってもらう（よかったこと・気になること・次に試すこと・続けること）
- XのAnalyticsのCSVやスクショを追加して、より詳しい振り返りをしてもらう（任意）

## 重要な特徴

- **データはすべてあなたのPC上に保存されます。** クラウドには送信されません。
- **AI分析を実行したときのみ**、確認いただいたデータ（記録の内容や、アップロードしたスクショ・CSVの内容）をGoogleのGemini APIへ送信します。
- Gemini APIキーはブラウザのセッション中のみ保持され、アプリを閉じると自動的に消去されます。ディスクに保存されることはありません。
- 専用のインストーラーはありません（Python・依存ライブラリを別途インストールしていただく必要があります）。

## セットアップ手順

### 1. Pythonをインストールする

まだインストールしていない場合は、以下からダウンロードしてください。

https://www.python.org/downloads/

インストーラーを起動したら、**画面下部の「Add python.exe to PATH」に必ずチェックを入れてから**「Install Now」をクリックしてください。

インストール後、コマンドプロンプト（Windows）またはターミナル（Mac）で以下を実行して確認してください。

```
python --version
```

`Python 3.x.x` のように表示されればOKです。

### 2. このリポジトリをダウンロードする

右上の「Code」ボタン→「Download ZIP」からダウンロードし、任意の場所に展開してください。

### 3. 依存ライブラリをインストールする

展開したフォルダの中でコマンドプロンプト（またはターミナル）を開き、以下を実行してください。

```
pip install -r requirements.txt
```

### 4. Gemini APIキーを取得する

1. https://aistudio.google.com を開き、Googleアカウントでログインする
2. 左メニューの「Get API key」→「Create API key」をクリックする
3. 表示された `AIza...` から始まる文字列をコピーしておく（この画面を閉じると再表示できないので注意）

### 5. Google Cloudの予算アラートを設定する（推奨）

Gemini APIは使った分だけ課金される従量課金制です。想定外の請求を防ぐため、以下の設定を強く推奨します。

1. Google Cloud Console（https://console.cloud.google.com） を開く
2. 「お支払い」→「予算とアラート」を開く
3. 月額の上限（例：500円）を設定し、50%・90%・100%到達時にメール通知を受け取るよう設定する
4. 利用可能な場合は「Spend Cap Budgets（支出上限予算）」も併用することを推奨します。通常の予算アラートは通知のみで、APIの利用を自動的に止めるものではない点にご注意ください。

### 6. 起動する

`run.bat`（Windows）をダブルクリックしてください。

起動時にWindowsのセキュリティ確認が表示される場合がありますが、「アクセスを許可する」を選択してください。ブラウザが自動的に開き、X簿の画面が表示されます。

## 使い方

1. サイドバーにGemini APIキーを入力する（毎回の起動時に入力が必要です）
2. 「記録」タブで、今日のフォロワー数や「今日やったこと」を記録する
3. 数日記録がたまったら、「振り返り」タブでAIに振り返ってもらう
4. 「データ追加」タブから、XのAnalyticsのCSVやスクショを追加すると、より詳しい振り返りができます（任意）

記録がなくても、CSV・スクショだけで振り返りを利用することもできます。

## ご利用にあたっての注意事項

- XのAnalyticsのスクリーンショットをアップロードする際は、他のユーザーの情報（リプライ相手の名前など）が写り込んでいないかご確認ください。
- 本アプリのAIによる振り返りは、正確性や成果を保証するものではありません。参考情報としてご利用ください。
- データはローカルのSQLiteファイル（`data/xbook.db`）に保存されます。暗号化はされていないため、PC自体の管理にはご注意ください。
